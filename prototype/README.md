# Prototype

This directory is where the sprint prototype will live. Nothing is scaffolded here.

## Technology Decision

The team chooses the prototype medium on Day 4 and records it in `docs/design-decisions/0001-prototype-technology.md`. Do not assume HTML, Figma, or any other medium before that record exists.

The production stack is a separate decision, recorded on Day 1.

## After the Decision

Build only in the chosen medium, and only as far as the critical flow needs for review and informal testing. Map what you build to the production stack in `production-reference/`.

The prototype is a disposable facade for usability testing. It is not production code.
