# Sprint Journal

Chronological record of sprint activities, decisions, and progress.

## Naming Convention

`day-N-phase.md` — using the phase name for each day:

| Day | File |
|-----|------|
| 1 | `day-1-understand.md` |
| 2 | `day-2-ideate.md` |
| 3 | `day-3-decide.md` |
| 4 | `day-4-ux-foundation.md` |
| 5 | `day-5-ux-foundation.md` |
| 6 | `day-6-ux-advanced.md` |
| 7 | `day-7-ux-advanced.md` |
| 8 | `day-8-prototype.md` |
| 9 | `day-9-prototype.md` |
| 10 | `day-10-review.md` |
