# References

Catalog of external references gathered during the sprint.

## Creating Reference Entries

Use `/reference-gathering` to fetch and catalog references. For quick references, append to this file. For substantial references, create a separate file in this directory.

## Reference Format

```markdown
### [Reference Title]
- **Source:** [URL or file path]
- **Type:** [Documentation / Brand / Competitor / API / Inspiration]
- **Key takeaways:**
  - Point 1
  - Point 2
- **Sprint relevance:** [How this informs our work]
```
