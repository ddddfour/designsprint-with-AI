# Design Decisions

Architectural decision records for significant design and process choices made during the sprint.

## Naming Convention

`NNNN-title.md` — e.g., `0001-prototype-technology.md`, `0002-navigation-pattern.md`

## Creating Decision Records

Use `/sprint-documentation` when a significant decision is made. Template is in `.claude/skills/sprint-documentation/assets/templates/decision-log-template.md`.

## When to Create a Record

- Technology or tool choices
- Design direction selections (Decide & Storyboard)
- Scope changes during the sprint
- User flow architecture decisions
- Any choice the team might want to revisit or explain to stakeholders
